# MagicFold 0.15

## Pantalla completa
Configuració (engranatge) → Pantalla completa: activada/desactivada.
L'opció és independent del tema i es conserva quan es reinicia el launcher,
es plega el mòbil o es torna d'una altra app. Amaga les barres d'estat i
navegació amb l'API pública d'Android. Un gest des de la vora les mostra
temporalment; no és un mode quiosc. La barra pròpia amb Trucades, WhatsApp
i Agenda continua disponible. El teclat i la cerca d'apps segueixen funcionant.
No canvia la pantalla completa de les altres aplicacions.

## Linux · Hacker desktop
Configuració → Temes i perspectiva → Linux · Hacker desktop.
Tema independent de Terminal: fons de graella verd petrolí, panells foscos,
tipografia monoespaiada, accents fòsfor i ambre i barres de terminal.
Amb el mòbil obert, els panells del launcher es poden moure, redimensionar,
maximitzar i minimitzar. La seva disposició es desa per a aquest tema.
També admet foto pròpia, perspectiva amb el sensor, agenda i temps reals.
No executa ordres, no mostra accessos de xarxa ficticis ni ofereix una shell.
Les finestres d'altres apps continuen depenent de MagicOS i de cada app.

Implementació immersiva: https://developer.android.com/develop/ui/views/layout/immersive
